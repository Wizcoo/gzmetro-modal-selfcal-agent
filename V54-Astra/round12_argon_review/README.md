## 需要先纠正的结论

1. **2q不是写错的最优系数。** 当前代码有意选择历史二阶能量不劣的边界。对单一固定分布，q才是该标量二次损失的最小点；min_n q不自动成为池化或最坏损失的全局最优。z是观测，未有独立真值，残差能量最小也不等于真实位移误差最小。
2. **不能用两个中位偏移之差倒算源码q。** ZXJ6实际三夜最小q为0.7605955。Argon用6.148与11.267倒算0.546，混用了当前夜描述量与历史统计；两个中位数之差也不等于逐帧补偿的中位数。
3. **Huber与Tukey不等价。** Huber超阈值后保持非零权重，Tukey可以变为零；因此“Huber/Tukey自动100%保留”不成立。[Huber官方权重定义](https://www.statsmodels.org/stable/generated/statsmodels.robust.norms.HuberT.weights.html)，[Tukey官方权重定义](https://www.statsmodels.org/stable/generated/statsmodels.robust.norms.TukeyBiweight.weights.html)。本轮按附件阈值做一次重算：ZD3204的1pixel阶跃，Huber只保留约88.63%，Tukey在该理想单点场景保留100%。
4. **总杠杆guard=0.5不会拦住h=0.3604的点。** 改成总杠杆有诊断意义，但不能声称这一步本身修复ZD3204。LOO的分母截断到0.1后也不能继续称“精确LOO”。
5. **主模态与高阶模态尚无已证实的物理身份。** PCA按统计能量排序，不能未经几何或独立数据验证就把第一阶称为相机平移/旋转、其余称为局部弯曲噪声。每夜分量可能相关，单独收缩时需要考虑联合预测及近重特征值的基旋转。

## 增量公式的直接反例

按原文公式，理论补偿u走0→1→0，上升只接受一半、回退按其规则完全放行：

|时刻|理论补偿u|alpha|实际补偿c|
|---|---:|---:|---:|
|0|0|0|0|
|1|1|0.5|0.5|
|2|0|1|−0.5|

最后一帧满足其 `abs(u)<abs(c_prev)` 回退条件，却留下−0.5补偿；如果真实设备扰动已回零，输出出现+0.5假残留。恢复应依据实际已接受的补偿状态和独立证据重新设计，不能照搬理论增量积分。

实际327479/11-12的03–06，ZJ5/6/7/8整体仍欠补，算法基准下残余均值约+0.347/+0.187/+0.424/+0.857；ZXJ6同时约−5.118过补。不能据“J没有过补”推断ZXJ6载荷可靠，也不能承诺该J刹车必然抓住这次失败。这里只报告时段整体状态，不声称每帧符号一致。

## 建议的实施次序

先固定一套明确的LOO+稳健权函数及退化处理，单独比较当前解算；再独立比较历史gain=2min_q与min_q。二者分别过真实夜和已知真值反例之后，才考虑组合。模块3应先改正恢复、过冲和可观测性问题，再做状态机试验；不要三模块同时改后只看通过率。

固定测试需包括孤立与成组真实阶跃、纯设备扰动、空间关系准确/失配两种相消、平稳点与其他点扰动、参考缺失、ROI集合变化、补偿闭合往返、恢复信任、时间边界和重启。最后仍需从raw经过W3/Modal/S2/S1完整链，检查峰谷时间和状态连续性。0.08、3倍尺度、分母0.1和正则lambda均是待验证规则，可以作为内部统一规则研究，但尚无证据保证跨设备无需调整。
